# Data Dictionary

## Products

| Column | Description |
| ProductID | Unique product identifier |
| ProductName | Product name |
| ProductCategory | Product Category |
| UnitCost | Product unit cost |
| SellingPrice | Product selling price |

## PurchaseOrders

| Column | Description |
| PurchaseOrderID | Purchase order identifier |
| SupplierID | Supplier reference |
| ProductID | Product reference |
| QuantityOrdered | Quantity purchased |
| OrderDate | Date of order |
| ExpectedDeliveryDate | Requested delivery date |
| ActualDeliveryDate | Actual date of delivery |
